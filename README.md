# Дарья Андрианова — портфолио

React + TypeScript + Vite. Готовый сайт для GitHub Pages находится прямо в корне репозитория.

## GitHub Pages

В **Settings → Pages** выберите **Deploy from a branch**, ветку с проектом (например, `main`) и каталог **/(root)**.

Корневой `index.html` уже подключает собранные JS и CSS из `assets/`. Сборка на стороне GitHub не требуется. `.nojekyll` отключает обработку Jekyll. Все пути относительные и работают в подпапке репозитория.

## Разработка

Рекомендуется Node.js 22 LTS и npm. Команды запускаются из корня проекта.

```sh
npm ci
npm run dev
```

Для разработки Vite использует исходный шаблон `app.html` и автоматически показывает его на `/` с горячим обновлением.

## Обновление готового сайта

```sh
npm test
npm run build
```

Сборка проверяет TypeScript и обновляет **корневые `index.html`, `assets/` и `.nojekyll`**. После правок коммитьте их вместе с исходниками. Скрипт `scripts/prepare-pages.mjs` автоматически заменяет предыдущие файлы публикации. `dist/` остаётся промежуточным каталогом и исключён из Git.

## Локальный просмотр готового сайта

```sh
python3 -m http.server 8080
```

Откройте `http://localhost:8080/`. Через `file://` браузеры ограничивают загрузку ES-модулей, поэтому нужен HTTP-сервер. `npm run preview` также показывает готовую сборку.

## Структура

- `index.html` — готовая страница для публикации
- `assets/` — готовые JS, CSS и материалы сайта; входят в Git
- `.nojekyll` — настройка GitHub Pages
- `app.html` — исходный HTML-шаблон Vite
- `src/` — компоненты, тексты, стили и эффекты
- `public/assets/` — исходные изображения, SVG и шрифты; копируются в корневой `assets/` при сборке
- `scripts/prepare-pages.mjs` — подготовка корня к публикации
- `vite.config.ts` — относительные пути и вход разработки
- `tests/` — проверки типографики и материалов галерей
- `AGENTS.md`, `TYPOGRAPHY.md` — правила дальнейших правок
- `local-archive/` — исходные материалы, дубликаты и скриншоты; исключены из Git и не нужны для сборки

## Содержимое

- `src/config.ts` — ссылки, параметры Warp и стекла
- `src/drawerContent.ts` — тексты и структура шторок
- `src/galleries.ts` — галереи компаний
- `src/ContestCase.tsx` — конкурсный кейс
- `src/AvatarEasterEgg.tsx` — пиксельный аватар и пасхалка

`public/assets/real.jpg` — браузерная копия предоставленной HEIC-фотографии. Исходный файл сохранён в локальном архиве.

Зависимости, промежуточная сборка, архив, локальные настройки и `.env` исключены через `.gitignore`. `package-lock.json` хранится в Git для воспроизводимой установки. Отправка в удалённый репозиторий отдельно не выполнялась.
